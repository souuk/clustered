# Candidate Hardware Visualizations

These graphics are derived from the supplied course handouts and are not yet
referenced by `poster/main.tex`.

- `dual-rail-psu.svg` and `.png`: simplified functional overview of the JE215
  dual-rail supply. It shows the center-tapped transformer, positive and
  negative rectification/filtering branches, LM317 and LM337 regulators, and
  the three output rails. It is not a substitute for the original construction
  schematic.
- `teensy-interface.svg` and `.png`: simplified Teensy 4.1 interface map based
  on the supplied 2025 wiring list. It records the LCD, stepper, ADC-DAC, SD
  card, DAC-channel, and power-domain relationships relevant to the STM.

The SVG files are the editable masters. The PNG files are poster-ready exports.
Verify both graphics against the final assembled hardware before publication.
